# Брендовые ассеты Vaka

Логотип — чат-бабл с хвостиком и «голосовой волной» из пяти полос, выстроенных в силуэт буквы V. Центральная полоса — терракотовый акцент (точка записи голосового). Палитра совпадает с Telegram Mini App (`miniapp/src/styles.css`).

## Файлы

| Файл | Назначение |
|------|-----------|
| `logo-mark.svg` | Основной знак, тёмная тема (бабл `#c7a287`, полосы прозрачные, акцент `#A7674E`) |
| `logo-mark-light.svg` | Знак для светлых фонов (бабл `#6b5142`) |
| `logo-mark-mono.svg` | Монохром, весь знак `currentColor` — стикеры, watermark, печать |
| `logo-lockup.svg` | Горизонтальный лочап знак + «vaka», тёмная тема |
| `logo-lockup-light.svg` | Лочап для светлых фонов |
| `avatar.svg` | Аватар бота: сплошной фон `#28211d`, знак вписан в круглый кроп Telegram |
| `favicon.svg` | Упрощённая версия (3 полосы) для 16–32 px |

## Правила использования

- Полосы волны — прозрачные вырезы (маска), знак работает на любом фоне; исключение — `avatar.svg` со сплошным фоном.
- В мелких размерах (≤32 px) использовать только `favicon.svg` — пять полос сливаются.
- Шрифт лочапа — Inter Medium (шрифт Mini App); текст в SVG не переведён в кривые, для сред без Inter экспортировать в PNG.
- Палитра: тёмная тема `#c7a287` / `#D29B82` на `#28211d`; светлая `#6b5142` / `#A7674E` на `#F7F3ED`.

## Экспорт PNG

Telegram принимает аватар как квадратный PNG/JPEG ≥512×512: рендерить `avatar.svg` в 512×512 (например, `npx svgexport` или Inkscape). Для лендинга — favicon 32/180/512 из `favicon.svg` и `logo-mark.svg`.
